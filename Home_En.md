This manual provides help regarding the various features of this page.

# Header
![header](https://i.imgur.com/vbNO0NV.png)

Starting from the left, there's a switch that allows you to change the language between: Spanish (ES), French (FR) and English (EN).
There's a bell icon on the right, which can be used quickly to turn on/off push notifications of the application in the phone.

# Real-time Meter
![meter](https://i.imgur.com/nQ44394.png)

This meter will update in real-time with the values measured at each instant. It also updates the values detailed below:
- Average: Shows the arithmetic mean of all values since the meter started.
- Maximum: Shows the maximum value recorded since the meter started.
- Minimum: Shows the minimum value recorded since the meter started.

# Interaction Buttons
![interaction buttons](https://i.imgur.com/1TvU3NB.png)

Starting from left to right:
- Measurement History: Shows raw data of all measurements taken by the application. For additional information in the form of graphs and heat maps, please go to the "Statistics" section.
- Pause/Stop: By default, the meter will be active, so pressing this button will stop it. If pressed when the meter is stopped, it will have the opposite effect and activate it.
- Alert History: Shows the history of alerts received by researchers so the user is aware of possible risks regarding loud noises.

## Measurement History
![measurement history](https://i.imgur.com/OyKk1eC.png)

This section displays the different measurements, including information such as date, location, and level. The trash can icon can be used to remove the measurement from the list.

To navigate through the different table views, use the arrow keys at the bottom.

## Alert History
![alert history](https://i.imgur.com/bmZWnZI.png)

This section displays the various alerts that researchers publish for users. It includes information such as date, location, and severity. The trash can icon can be used to remove the item from the list.

There are 3 types of alerts:
- Low: May be annoying but will not cause damage.
- High: Long-term and repeated exposure can cause ear damage.
- Critical: The noise is so loud that even minimal exposure can cause problems.


To navigate through the different table views, use the arrow keys at the bottom.
